# Gray Pixel lore (draft v0, 2026-10-13)

Status: working canon. Freddy is collecting more lore from the Discord and will revise after demo feedback. Game text is English.

## Canon so far
- **The gray pixel:** at the Ballerz mint some crazy-hair Ballerz NFTs got one random gray pixel in the wrong place. It is a **virus, or a gate to another dimension**, which opens into this card-game dimension.
- **The Grid:** the alternate arena where Ballerz exist as **cards**. One Baller can have **several versions (glitches)** of themself in the Grid.
- **Arena only for now:** how players face each other is undecided (later).
- **Coaches:** victims trying to help the players. They are not guardians.
- **Delivery:** lore unlocks through the **story** (each court gives a piece), plus card flavour text.
- **Tone:** not corny; subtle hints, dry humour allowed. Ghost in the Shell mood (quiet, uncanny), never slapstick.
- **Title screen:** the "A" in GRAY occasionally glitches into "&" for a moment.
